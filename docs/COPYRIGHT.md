# Copyright and Publication Boundary

## 공개하는 자료

- 2026년 재구현 source
- 독립적으로 작성한 test
- 직접 작성한 기술 설명과 검토 결과
- 개인정보를 제거한 새 실행 screenshot

## 공개하지 않는 자료

- 교수·강의 제공 PDF, DOCX, slide, 문제, 예제, test
- 과제 보고서와 원본 screenshot
- 학번·이름·주소·IP 등 개인 식별 가능 정보
- 제출 ZIP, `.exe`, `.o`, binary build artifact
- 배포된 텍스트·이미지 resource
- 강의 예시와 본인 기여를 명확히 나누기 어려운 원본 코드

`local-review/`는 원본과 2026년 코드를 비교하기 위한 로컬 자료이며 `.gitignore`로
제외합니다. Git 초기화 전에 `git status --ignored`로 제외 상태를 다시 확인합니다.

저장소 공개 전 LICENSE 선택이 필요합니다. 기반 project를 복사하지 않은 독립 코드이므로
본인이 원하는 공개 조건을 확인한 뒤 추가합니다.
